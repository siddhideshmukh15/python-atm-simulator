# ATM Simulator

A simple **ATM Simulator** built using Python. This beginner-friendly project allows users to check their balance, deposit money, withdraw money, and exit the ATM.

## Features

- PIN verification
- Check account balance
- Deposit money
- Withdraw money
- Check insufficient balance
- Exit the ATM

## Technologies Used

- Python
- While Loop
- If-Else Statements
- User Input
- Arithmetic Operations
